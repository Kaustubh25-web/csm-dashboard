    How upload merges

    • Accounts match by name (not case-sensitive). Filled cells overwrite; blank cells never erase what is already saved.
    • Meetings are de-duplicated (same account, date, type and summary), so re-uploading the same file is safe.
    • “Replace all” clears every account and meeting first.
